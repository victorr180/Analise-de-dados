

# Projeto Victor

Análise de uma carteira de crédito com 250 contratos, feita inteiramente em Excel.

## Sobre o projeto

O projeto organiza uma base de dados de empréstimos e analisa o comportamento da carteira por tipo de crédito, nível de risco, região e gerente responsável, apresentando os resultados em um dashboard interativo.

## Estrutura do arquivo

- **Dados**: base bruta com 250 contratos e 11 colunas — ID do cliente, data do contrato, tipo de crédito, valor emprestado, taxa, prazo (meses), score, risco, status (em dia, atraso, inadimplente), região e gerente.
- **Analise**: tabelas dinâmicas cruzando valor emprestado por risco, quantidade de contratos por tipo de crédito, valor emprestado por gerente e por região, e contratos em atraso.
- **Dashboard**: painel com 5 gráficos de barras (valor por risco, contratos por tipo de crédito, valor por gerente, valor por região, indicador de atraso) com filtros interativos (segmentações) por Risco, Status e Prazo.

## Tipos de crédito analisados

Crédito Consignado, Crédito Pessoal, Crédito Imobiliário, Cartão de Crédito e Financiamento de Veículo.

## Ferramentas utilizadas

- Excel (fórmulas: SOMA, MÉDIA, CONT.SE, SE, SOMASE, PROCV)
- Tabelas Dinâmicas
- Segmentações de Dados (slicers)
- Gráficos e Dashboard interativo

## Objetivo

Projeto criado como prática pessoal na preparação para a área de dados.
