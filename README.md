# Análise de Dados — Carteira de Crédito

Repositório com dois projetos de análise da mesma carteira de crédito, praticados em ferramentas diferentes.

## Projetos

### 📊 [Excel/](./Excel)
Análise feita em Excel: base de dados de 250 contratos de crédito, tabelas dinâmicas cruzando risco, tipo de crédito, região e gerente, e um dashboard interativo com gráficos e filtros (slicers).

### 📈 [PowerBI/](./PowerBI
A mesma análise recriada em Power BI, praticando modelagem de dados e criação de dashboard nessa ferramenta.

## Objetivo

Projetos criados como prática pessoal na preparação para a área de dados, aplicando os mesmos conceitos de análise em duas ferramentas diferentes.

## Ferramentas utilizadas

- Excel (tabelas dinâmicas, segmentações de dados, fórmulas: SOMA, MÉDIA, CONT.SE, SE, SOMASE, PROCV)
- Power BI
